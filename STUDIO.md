# Живой офис Axium

Отдельная страница: `studio.html`. Существующие `index.html` и `showcase.html` не меняются.

Автоматический свет использует `Asia/Almaty` (UTC+5), а не время устройства: 08:00–16:59 — день; с 17:00 окна становятся темнее, к 19:00 — ночь; с 06:00 до 08:00 — рассвет. Кнопки «День», «Вечер», «Ночь» показывают ручной предпросмотр. «Авто» возвращает реальное время. Это заданное расписание, а не астрономический закат.

В сцене: кофейная станция, съёмочное оборудование, четыре человека и робот. Экраны мягко меняют яркость, над кофе поднимается пар, персонажи периодически перемещаются по свободной части пола. Движение персонажей выполнено из статичных PNG/WebP-фигур; отдельных кадров походки и анимации рук пока нет. Робот — визуальный персонаж, чат не подключён.

Задачи читаются из того же Google Apps Script API, что использует доска. Откройте `studio.html?k=ВАШ_КЛЮЧ`. Без ключа сцена работает самостоятельно и не подставляет вымышленные задачи. Откройте персонажа, чтобы увидеть его задачи, включая ожидание клиента. Имена в `owners` сопоставляются с Димой, Дарьей, Эллиной и Максимом без учёта регистра. Ключ не сохраняется в localStorage; исходящие ссылки не передают Referer.

Нет npm-зависимостей и шага сборки. Для GitHub Pages достаточно файлов `studio.html` и `assets/office/`. Проверки: `node --test tests/studio.test.mjs`. Анимации останавливаются в скрытой вкладке и при системном `prefers-reduced-motion`; переключатели света, команды и движения сохраняют предпочтения локально. Изображения сгенерированы специально для проекта; исходные PNG сохранены в диалоге, сайт использует компактные WebP с альфа-каналом для персонажей.
